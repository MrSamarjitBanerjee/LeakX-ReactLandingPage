# LeakX — React Landing Page

A modern, responsive React landing page for **LeakX**, an npm CLI tool designed to detect sensitive data and potential secrets in codebases.

The landing page presents LeakX's features, CLI workflow, installation instructions, roadmap, and project background through a clean, developer-focused interface.

## Tech Stack

- React.js
- JavaScript (ES6+)
- Vite
- HTML5
- CSS3
- Git & GitHub

## React Concepts Practiced

- Functional Components
- Component Composition
- JSX
- `useState`
- `useEffect`
- Event Handling
- Conditional Rendering
- List Rendering with `.map()`
- React `key` prop
- Dynamic Class Names
- Browser Event Listeners & Cleanup
- Responsive Component Design

## Run Locally

```
git clone <repository-url>
cd leakx-landing
npm install
npm run dev
```

The application will start on the local development server provided by Vite.

## LeakX CLI

LeakX can be installed globally through npm:

```
npm install -g leakx
```

After installation, the leakx command can be used directly from the terminal.
